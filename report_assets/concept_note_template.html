2. Problem Statement / Objective

Today, many job seekers and students struggle to pass the initial automated screenings conducted by Applicant Tracking Systems (ATS). Free resume tools frequently fail to offer comprehensive grading, structured career suggestions (such as project ideas or certifications), or contextual mock interview questions. Additionally, many users are concerned about data privacy when uploading personal details to third-party servers.

ResuMind AI solves this problem by offering a modern, privacy-first, database-free resume analysis platform. Resumes uploaded as PDF or DOCX files are parsed directly into text in-memory and analyzed transiently via LLM APIs. The system outputs comprehensive grading scores, key strengths, weaknesses, missing keywords, best job roles, optimized summary variations, and interactive mock interview questions, with zero data retention.

3. Target User & Use Case
  • Primary user: An individual job seeker, student, or professional seeking an interactive, privacy-respecting ATS grading assistant with summary optimization and custom mock interview practice.
  • Secondary user: A career counselor or university recruitment coordinator who wants to quickly review applicant resumes without storing candidate details or raising privacy compliance issues.
  • Core use case: Upload resume (PDF/DOCX) → Extract text in memory → Transient LLM analysis → Render live visual dashboard with gauges, strengths, keyword gap alerts, improved summary comparisons, and accordion-style mock interview practice → Save/print report vector PDF.

4. LLM Model & API Used
Provider Google Gemini API (with fallbacks for OpenAI, Claude, Grok, and OpenRouter)
Models gemini-3.5-flash — default, high-speed, cost-effective responses
gemini-3.5-pro — selectable for deep structural career evaluations
Configurable parameters API key authentication, active provider toggles, and model selections managed through backend environment configurations.
Auxiliary use of LLM Sanitizes raw output streams, extracts structural JSON matching strict schemas, and generates contextual STAR-based interview questions.
5. Key Features of the Application
  • Secure Document Parsing: PDF.js and Mammoth.js process files entirely in Express memory buffers, extracting content without persistent file writing.
  • In-Memory Transient Processing: Zero database footprints or file tracking. Uploads are analyzed immediately and data is returned directly to the client browser.
  • ATS Scoring Gauges: Visual progress metrics representing Overall Score, ATS Compatibility, Grammar & Style, and Skills Match.
  • Career Analytics Panels: Highlights quantified strengths, improvement points, missing industry skills, and target job titles.
  • Interactive Mock Interview Accordion: Generates tailored interview questions based on candidate experience, offering structured STAR coaching tips.
  • Professional Summary Optimizer: Compares original and improved summaries side-by-side with copy-to-clipboard functionality.
6. Expected User Experience & Outcomes
  • Intuitive Dashboard: Users receive immediate, transparent feedback on their resumes in a clean glassmorphic dashboard (supporting dark/light theme).
  • Empowered Job Application: Concrete recommendations on missing keywords, certifications, and projects help candidates bypass automated ATS bots.
  • Effective Interview Prep: Candidates can review and practice custom interview prompts with Star-method tips, preparing them for hiring discussions.
